# Security reports

Found a security problem in flop-lab? The maintainer is [@zkasuran](https://github.com/zkasuran).

Use [GitHub private vulnerability reporting](https://github.com/zkasuran/flop-lab/security/advisories/new) when the repository offers it. The GitHub API reported this feature disabled on 2026-11-06. If it is unavailable, open a [contact request](https://github.com/zkasuran/flop-lab/issues/new) titled `Private security contact requested` and mention @zkasuran. Include no exploit details. Ask for a private channel before sending the report.

In that private channel, include the affected commit, route or package, a minimal reproduction, the observed impact and the environment. Remove credentials, wallet material and personal data from attachments. Keep testing local or on a deployment you control.

There is no bug bounty or promised response time. Fixes target the current main branch. Older revisions have no separate maintenance commitment.

See [the web threat model](docs/SECURITY.md) for the reviewed boundaries, operating limits and known dependency findings. A signed commit or a passing suite check is not a security certification.
