## Remaining tool-logic concerns

These require decisions in their owning tools. They are local suite findings,
not newly established defects in a FLOP service.

### Gateway price units differ across tools

The [console calculator](../packages/console/src/core.ts) labels gateway price
arithmetic as FLOP per token. Its recorded gateway response at
`2026-11-05T23:31:27.892Z` supplies `prompt: "0.006"`, `completion: "0.006"` and
`input_cache_read: "0"` without a currency or token-unit declaration in those
pricing fields. Two replays at `2026-11-06T17:44:59Z` returned `9` for the chosen
1000 input tokens and 500 output tokens.

The [model registry](../packages/models/README.md#prices-and-history) and
[exporter](../packages/export/README.md#stable-v1-columns-and-types) instead keep
gateway units unspecified. The arithmetic is reproducible; its FLOP/token label
needs a shared authoritative citation or an explicit assumption. It must not be
treated as a measured paid price.

```sh
pnpm exec tsx -e 'import { recordedConsole } from "./packages/console/src/recorded.ts"; import { tokenCost } from "./packages/console/src/core.ts"; const { estimate } = recordedConsole(); const p = estimate.gateway!; console.log(p, tokenCost(p.prompt, p.completion, estimate.input.tokens, estimate.input.outputTokens));'
```

### Watcher and challenger use different challenge clocks

[Watcher](../packages/watch/src/engine.ts) subtracts the stats
`latestBlockNumber` from `challengeEnd`. [Challenger](../packages/challenger/README.md#exact-block-windows)
uses reported finalized height and keeps missing finality unknown. Watcher's
README discloses its reported-head formula, but the tools can disagree under lag.

A labelled synthetic mutation of the recorded watch channel schema was evaluated
twice at `2026-11-06T17:44:59Z`. Best head was 3017225, finalized head was 3017174
and the forced claim deadline was 3017224. With a 100-block alert threshold,
Watcher emitted no alert and no note. The deadline still had 50 blocks remaining
against the supplied finalized head. The probe asserted the effective parsed
head before calling `evaluate` with fresh state.

This is not an observed chain incident. The alert clock should be reconciled
with the finalized-window policy, including missing-finality behavior. The current
watcher result is not a safe filing deadline.
