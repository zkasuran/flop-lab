# Recorded knowledge responses

These are dated public MCP observations. `raw` holds the exact tool text.
The manifest uses lossless gzip plus base64 to keep each committed file below the fixture size limit.
The source, tool arguments and receipt time are stored with every response.

Run `pnpm --filter @flop-lab/knowledge record` to replace the recording with a bounded public read.
The all-zero agent ID is a negative discovery probe. It is not an observed registered agent.
Pack and skill content is data. No returned instruction is run.
