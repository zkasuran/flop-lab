# Spec clause explorer

Does the public devnet evidence support a yellowpaper clause? This page shows the pinned package report with result filters and quoted sides. It uses the shared site tokens and Motion components.

From the repository root:

```sh
pnpm install --no-frozen-lockfile
pnpm --filter web build
pnpm --filter web exec next start --port 3400
```

Open `http://localhost:3400/spec`. The page and `/spec/report` use the same recorded comparison. The browser does not poll FLOP services. The CLI command on the page can replay it or make a bounded fresh comparison with `--live`.

The summary values arrive complete. Their entrance and proportion bars animate from real counts. The guide line tracks reading progress. Appendix selection uses a shared selection indicator. Row expansion uses layout animation and presence transitions. The shared shell supplies tool-grid route transitions. Reduced motion removes travel and makes state changes immediate.

Rows are grouped by appendix and shown in bounded batches. Search and result filters run over the complete report. Empty views explain what the lack of rows means. Source text is rendered as text, not Markdown or HTML.

## What this does not verify

The page does not verify deployed constants, runtime signatures, finalized inclusion, vector execution or implementation-status claims. It does not make the recorded comparison current. Catalog matches are not runtime certification. Browser checks cover the displayed recording and interaction paths, not an independent protocol audit.
